# The Music Time-Capsule Maze — Ananya Satheesh

## Theme
This maze explores music as cultural data through genres and technological change.

## Goal
Find the final message inside exit/solution.txt.

## How to Solve
Use only command-line navigation.

Helpful commands:
- ls
- cd <folder>
- cd ..
- cat <file>
- pwd
- ls -a   (reveals hidden files/folders)

## Windows Users
After unzipping the maze, run:

.\hide-dotfiles.ps1

to properly hide dotfiles before solving.

cd entrance
