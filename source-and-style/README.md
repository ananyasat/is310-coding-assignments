# Source and Style Analysis

The website I selected was :Library of Congress and I was looking at the National Jukebox collection. This collection offers free streaming of historic sound recordings along with metadata and contextual information.  It also features more than 10,000 recordings from Victor Talking Machine Company etween 1901 - 1925. 

Link: https://www.loc.gov/collections/national-jukebox/about-this-collection/

### Tech Used
 - HTML: the website is built using HTML, when I looked at the documentation I noticed <!DOCTYPE html> declarations and other elements such as <div> <head> etc which are used in HTML

 - CSS: The sites also uses external CSS files for styling. In the styles panel and Network tab I noticed a file named 'base.css' and other CSS variables. 
 - JavaScript - The site loaded multiple JavaScript files including 'base.js', ' selectivizr.js'. These are included through <script> tags in HTML. I think the JavaScript handles all the interactive elements on the site and other analytics the site tracks. 

 The National Jukebox website is maintained by the Library of Congress, a U.S. federal cultural institution. We can tell by its loc.gov domain and reference to library of congress in site metadata. The library of Congress has a dedicated web development team responsible for maintaining and updating the platform. 


 The National Jukebox site uses an HTML structure supported by CSS and JavaScript. The architecture seems pretty stable and the website works without any issues or lags.
